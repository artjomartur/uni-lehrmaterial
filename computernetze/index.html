Übungsaufgaben

1. Routing-Tabelle

Welcher Eintrag in einer Standard-Routing-Tabelle wird gewählt, wenn ein Paket an 192.168.1.55 gesendet wird?

  • A: 192.168.1.0 / 25
  • B: 192.168.1.0 / 26
  • C: 0.0.0.0 / 0
B (192.168.1.0 / 26). Nach dem Longest Prefix Match wird die spezifischste Route gewählt. /26 schließt Adressen von .0 bis .63 ein.

2. TCP vs UDP

Welche drei Hauptunterschiede gibt es zwischen TCP und UDP?

1. TCP ist verbindungsorientiert (3-Way-Handshake), UDP ist verbindungslos.
2. TCP bietet zuverlässige Übertragung (ACKs, Retransmission), UDP nicht.
3. TCP garantiert Reihenfolge und führt Fluss-/Staukontrolle durch, UDP ist schneller mit weniger Overhead.

3. Standard-Ports

Ordne die folgenden Ports ihren Protokollen zu: 22, 53, 80, 443.

22: SSH  |  53: DNS  |  80: HTTP  |  443: HTTPS
